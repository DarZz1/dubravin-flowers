# Папка фотографий товаров

Сайт сам подхватывает фото из этой папки — без загрузки через CMS.

Структура: `img/<ID товара>/<номер фото>.<расширение>`

```
img/
├── 1/            ← товар с ID = 1
│   ├── 1.jpg     ← первое фото (обложка карточки)
│   ├── 2.jpg     ← второе фото (галерея товара)
│   └── 3.png     ← расширения: .jpg, .jpeg, .png, .webp
├── 2/
│   └── 1.jpg
└── 57/
    ├── 1.jpg
    └── 2.webp
```

Правила:
- нумерация фото — подряд, начиная с 1 (максимум 8 фото на товар);
- сайт пробует расширения в порядке .jpg → .jpeg → .png → .webp;
- если фото нет — показывается фирменная заглушка;
- фото, загруженные через CMS, хранятся в localStorage браузера
  (в виде сжатых data-URL) и имеют приоритет над этой папкой.
